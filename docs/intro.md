# Introduction
This app is a project management suite aimed at organizing musical projects. It was created at the initiative of Melomania, a youth orchestra from Brussels. The app has features to manage recruitment, communications with the orchestra, accounting, has a contacts database designed for musicians, recording instruments, level, projects played,... More details about its use and functioning will be given in the next sections.
