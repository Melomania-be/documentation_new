# Files page

*Edited by Naomi*

## What is the Files page?

The Files page is Melomania's built-in file storage system. Think of it like a Google Drive integrated directly into the app. It lets you store and organize files without needing an external service like Dropbox or Google Drive. Files can be linked to a specific project or stored independently for general use.

---

## The Files Page

When you click on **Files** in the left sidebar, you see two tabs at the top right:

- **Projects** — files organized by project
- **General Files** — files stored independently from any project

---

## Projects tab

![Files projects tab](/img/using_the_app/files1.png)

This shows all projects as clickable cards. Each card displays the project name and the number of pieces it contains. Click on a project to open its file manager.

Inside a project's files you have two tabs:

### Material Management

![Material management](/img/using_the_app/files2.png)

This is where you manage the **score files** (PDFs of sheet music) for each musical piece in the project. Each piece is shown as a card — click on it to upload, replace, or delete its score materials. These are the files musicians download from the callsheet to prepare for rehearsals and concerts.

A piece can have **multiple materials** — for example different annotated versions for different conductors or concertmasters.

> ⚠️ If a piece is missing its material, the app will warn you with a yellow banner on the Project Details page.

### File Structure

![File structure](/img/using_the_app/files3.png)

This is a folder-based file explorer where you can organize any other files related to the project — posters, photos, recordings, administrative documents, etc.

From the File Structure you can:
- **Create folders** to organize your files
- **Upload files** into any folder (single or multiple files at once)
- **Preview files** directly in the browser — images, PDFs, audio, and video files can all be previewed without downloading
- **Download files**
- **Share a folder** — makes the folder accessible on the project's callsheet so participants can view and download files directly
- **Revoke sharing** — removes a folder from the callsheet
- **Rename** files or folders
- **Delete** files or folders

Right-clicking or using the **⋮ action menu** on any file or folder gives you all available options.

---

## General Files tab

![General files](/img/using_the_app/files4.png)

This tab stores files that are not linked to any specific project. It works the same way as the File Structure tab — you can create folders, upload files, navigate into subfolders, preview and download files, and manage everything the same way.

This is useful for:
- Administrative documents used across multiple projects
- Templates (poster templates, email templates, etc.)
- Any files you want to keep in the system without attaching them to a specific production

---

## Tips
- Always upload score files (materials) for each piece in a project — the app warns you on the dashboard if any are missing
- Use **Share folder** in the File Structure tab to make project folders visible on the callsheet for participants — this avoids sending files by email
- Files can be **previewed directly** in the browser without downloading, which is useful for quickly checking a score or poster
- The **General Files** tab is a good place for documents you reuse across multiple projects
