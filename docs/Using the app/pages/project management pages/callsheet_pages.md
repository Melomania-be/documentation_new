# Callsheet pages
## Main callsheet page
![Main callsheet page](/img/using_the_app/callsheet_main.png)
This is the callsheet version management page. When a callsheet needs to be updated, the user can choose whether to edit the existing callsheet or create a new version, from scratch or from the previous one. The app can then keep track of which musicians have opened the last version of the callsheet (see the dashboard). This feature allows to make sure the information is correctly circulating in the orchestra, and if necessary (if a musician hasn't gotten the emails or can't open the callsheet for some reason, or missed an update) take actions to rectify the situation. This page shows all the existing versions of the callsheet with some basic features (search a version, create a new one from scratch or from the last version). 

## Callsheet editing page
![Callsheet editing page](/img/using_the_app/callsheet_edit.png)
![Callsheet editing page](/img/using_the_app/callsheet_edit2.png)
This page allows to edit a callsheet. On the right, it shows a preview of the callsheet, and on the left, the editor. The callsheet is has default information on top, and then all the custom information, organized in blocs. The default informations (that cannot be edited) are the program and scores (the scores are downloadable from there) and the calendar. At the bottom of the callsheet, the project managers are also displayed by default. The custom blocs previously had to be edited in raw HTML, but recently the editor has been upgraded to visual editors. They allow to format the text with styles, colors, fonts and all basic text formatting pictures, and to add pictures, videos, files, links, and Google Maps integrations. In the current version, the blocs cannot be moved after creation, but that should change soon.
At the top of the editor, there is a link to the callsheet itself, see below.
