## What is a Callsheet?

A callsheet is a page shared with all participants of a project. Think of it as the single source of truth for everything a musician needs to know — the program, the events, the scores to download, and the contact information of the project managers. Each participant receives a personal link to the callsheet when their registration is confirmed, and can access it at any time.

## Main Callsheet Page

![Main callsheet page](/img/using_the_app/callsheet_main.png)

This is the callsheet version management page. When a callsheet needs to be updated, the user can choose whether to create a new version from scratch or from the previous one. The app keeps track of which musicians have opened the latest version of the callsheet (visible on the project dashboard). This allows you to make sure information is correctly reaching all musicians, and take action if someone hasn't seen the latest update.

This page shows all existing callsheet versions with:
- **Version number**
- **Last updated date**
- An **arrow (→)** to open and edit that version

At the bottom you have two buttons:
- **"New callsheet"** — creates a brand new blank callsheet
- **"New callsheet from the last one"** — duplicates the most recently updated version so you don't lose previous content

## Callsheet Editing Page

![Callsheet editing page](/img/using_the_app/callsheet_edit.png)
![Callsheet editing page](/img/using_the_app/callsheet_edit2.png)

When you open or create a callsheet, the screen is split into two parts:

**Left side — the editor** where you build the content

**Right side — the live preview** where you see exactly what participants will see, updating in real time as you type

### The Editor

The editor has two required fields:

**Version** — a label for this version of the callsheet (e.g. 1, v2.1). This field is required — the app will block you from saving if it is empty.

**Contents** — this is where you add all the information. Click **"+ Add content"** to add a new section. Each section has:
- A **title** — the heading of that section (required — every section must have a title or the app will block saving)
- A **rich text editor** — where you write the content. The toolbar lets you format with bold, italic, underline, strikethrough, colors, bullet points, numbered lists, alignment, links, images, videos, and more. You can also embed a **Google Maps location** by typing an address — it will show an interactive map on the callsheet.

You can add as many sections as you need, and delete any section using the 🗑️ trash icon.

> **Note:** In the current version, content blocks cannot be reordered after creation. Plan your sections in advance before adding them.

At the top of the editor there is a **link to the callsheet** itself — this is the link you can share with participants.

## What Participants See (The Callsheet)

![Callsheet](/img/using_the_app/callsheet1.png)
![Callsheet](/img/using_the_app/callsheet2.png)
![Callsheet](/img/using_the_app/callsheet3.png)
![Callsheet](/img/using_the_app/callsheet4.png)

This is the callsheet as musicians see it. It is a completely static public page — one of the only public pages of the whole app. It shows:

- A **header banner** with the project name
- **Program and Scores** — all musical pieces with composer, opus number, and year. Each piece has a button to download the score PDF. If no file has been uploaded yet, it shows "Aucun fichier" (No file)
- **Events** — all rehearsals and concerts with date, time, location, and type (rehearsal or concert)
- **Your custom content sections** — all the blocks you added in the editor, in the order you created them
- **Contact Information** — the project managers with a note inviting participants to reach out for questions
- A **last updated timestamp** at the very bottom

## Tips
- Always fill in the version field before saving — the app will block you if it is missing
- Every content section must have a title — untitled sections also block saving
- Use **"New callsheet from the last one"** when making small updates to avoid rewriting everything
- You can notify all participants of an update via the **Mailing** tab → **"Send a callsheet notification"**
- If a piece shows "Aucun fichier", go to the **Files** page to upload the score for that piece
