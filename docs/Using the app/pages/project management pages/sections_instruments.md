# Sections and instruments pages

The sections and instruments tool allows the user to organize the musical structure used throughout projects. Through this page, the user can manage instruments, create sections associated with those instruments, and organize sections into groups.

## Main sections and instruments page

![Sections and instruments page](/img/using_the_app/sections_pic1.png)

This page is divided into three main parts: Groups, Sections and Instruments. Each category has its own management table and allows the user to create, edit, duplicate or delete entries. These tools are used throughout the application to organize participants and projects according to instruments and sections.


![Section group creation popup](/img/using_the_app/sections_group_popup.png)

The user can set the group name and select one or more sections to associate with the group. Existing groups can also be duplicated in order to quickly create similar structures without having to recreate every section assignment manually.

## Sections

Sections represent participant groups inside projects. A section is associated with one or more instruments and contains a size corresponding to the number of participants expected for that section.

The sections table displays the section name, its size, the associated instruments and action buttons allowing the user to edit, duplicate or delete a section.

When creating or editing a section, the following pop-up appears:

![Section creation popup](/img/using_the_app/edit_section_popup.png)

The user can set the section name, define the desired size and select one or more instruments associated with the section. These instruments are selected through a checklist directly inside the popup window.

Duplicating a section creates a copy containing the same size and assigned instruments, which can then be modified independently.

## Instruments

![Instruments page](/img/using_the_app/section_instruments.png)

The instruments section allows the user to manage all instruments available throughout the application. Instruments are categorized by family and can later be assigned to sections.

The instruments table displays the instrument name, its family and action buttons allowing the user to edit, duplicate or delete an instrument.

When creating or editing an instrument, the following pop-up appears:

![Instrument creation popup](/img/using_the_app/instruments_popup.png)

The user can define the instrument name and its family. Instrument families are used to organize instruments more clearly throughout the application.

Duplicating an instrument creates a copy of the selected instrument and its associated family, which can then be edited independently.
