This is the main page of a project, and shows an overview of the key aspects of a project. Here is a breakdown of this page
- The navbar at the top allows to navigate easily between the different management tools (mailing, accounting, recruitment, auditions,...). 
- Below that, it has a space where any important information (a new registration, a conflict in the recruitment page, a missing score to a piece,...) is highlighted, next to a few basic statistics.
- The project schedule is shown in a collapsed view that can be developed to see all the dates. Dates that are in the past have a grey background, to make it more visual during the project. 
- Project managers are the people whose contact information will be on the callsheet, that musicians can contact with questions. They are show here as well.
- Sections frame: this widget show the current state of the orchestra versus the theoretical numbers. The bar graph indicates for every section how full it is, providing an easy way to see where the most work remains in the recruitment process. The sections can be ordered in orchestral order or by fill rate using the button in the bottom. The edit button on the right takes the user to the project editing page, see corresponding documentation page.
- Callsheet frame: this shows the versions of the callsheet, their dates of creation and update, and what proportion of the orchestra has seen it. In case musicians have not seen it, the option appears to send them a personnal notification.
- Registration form frame: As for the callsheet frame, it shows the date of creation and update of the registration form. This is the form candidates have to fill out to participate in the project. 
- Pieces frame: This shows the pieces played in the project. The piece files tab is deprecated and will be empty because piece files have been replaced with material assignments.
