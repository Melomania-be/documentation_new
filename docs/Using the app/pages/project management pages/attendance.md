*Edited by Naomi*

## What is the Attendances tab?

The Attendances tab gives you a complete overview of which participants are present or absent for each event in the project. It is based on the attendance information that participants filled in when they registered. It is split into two tables: one for **Concerts** and one for **Rehearsals**.

## The Attendance Report

![Attendance page](/img/using_the_app/attendance2.png)

When you click on the **Attendances** tab inside a project, you see the **Attendance Report** page.

At the top right there is a red **"Download PDF"** button that generates and downloads a PDF version of the full report.

### How the table works

This page generates an attendance table based on the registration forms filled in by participants. Participants are arranged by section, and sections are displayed in orchestral order: strings first (violins, viola, cello, double bass, harp), then woodwinds, then brass, then percussion.

The table has:
- **Rows** — each participant, grouped by section. The section name appears as a bold grey header row before each group. If a participant is a **section leader**, their name is marked with a blue **(Leader)** badge.
- **Columns** — each event (concert or rehearsal) appears as a column, showing the venue and the date/time

For each participant and each event:
- **Green cell with ✓** — the participant is present for that event
- **Red cell with ✗** — the participant is absent for that event
- A **comment column** next to each event shows any comment the participant left about their attendance

The table automatically optimizes the space to accommodate possible comments.

### Concerts table
Shows attendance for all concert events, with each concert displayed as a column header showing the venue and date.

### Rehearsals table
Shows attendance for all rehearsal events, with each rehearsal displayed as a column header showing the venue and date range.

---

## Downloading the PDF

Click the red **"Download PDF"** button at the top right to generate a PDF version of the full attendance report. The PDF is generated directly in the browser — no server needed. If the generation fails, the app will show an error message.

---

## Tips
- This page is **read-only** — attendance is set by participants when they register, not by the admin
- Use the **Download PDF** button to get a printable version for rehearsals or concerts
- On mobile, the tables scroll horizontally so you can see all events
- If a participant's name appears in multiple sections, it means they registered for multiple sections in the project
