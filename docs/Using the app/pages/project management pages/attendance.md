# Attendance page
![Attendance page](/img/using_the_app/attendance1.png)
![Attendance page](/img/using_the_app/attendance2.png)
This page generates an attendance table based on the registration forms. It generates a different table for the concerts and for the rehearsals, and automatically optimizes the space to accommodate possible comments. Participants are arranged by section, and the sections are displayed in orchestral order. This page also features a button to download a pdf version of the table.
