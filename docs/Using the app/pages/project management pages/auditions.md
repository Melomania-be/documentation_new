# Audition management pages
The auditions tool allows the user to request an online audition from a candidate.
## Audition manager
![Auditions manager page](/img/using_the_app/audition_manager.png)
On this page, the user can see all auditions, either in progress or done. They can manage audition packages, request auditions from candidates pending validation (this is also possible from the participation validation page), and visualize the auditions in order to make a decision (confirm participation or turn it down). An audition package is composed of one or more pdf files (of the excerpts the candidate has to record) and corresponding explanations (precise place to start, etc.). A project must have an audition package per section. These can be created when needed (it is not necessary to make one for every section from the start). To manage audition packages, go to "PDF management".

## Audition package manager
![Auditions package manager page](/img/using_the_app/audition_packages1.png)
![Auditions package manager page](/img/using_the_app/audition_packages2.png)
On this page, the user can manage and create audition packages for every section. When adding a file to a package, the following pop-up appears:
![Auditions package manager page](/img/using_the_app/audition_packages3.png)
A file has a title, an optional description (sometimes not needed, if the excerpt is already indicated in the score for example), and a display order.
## Requesting an audition
When the user wants to request an audition, they have to configure the audition package, and then go to the applications page, and click "request audition". The following window appears: 
![Auditions request](/img/using_the_app/audition_request1.png)
![Auditions request](/img/using_the_app/audition_request2.png)
The user can set a personnalized message, also add excerpts specific to that person that are not in the package, and set a deadline for the audition.
