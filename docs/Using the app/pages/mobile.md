# Mobile App Installation Guide

*Edited by Borshon*

This page explains how to install and run the Melomania app on mobile devices (Android and iOS).

---

## 📱 Android Installation (APK)

Since the app is hosted directly in our GitHub repository (instead of the Google Play Store), you can sideload it onto your phone using the Compiled Application Package (`.apk`).

### Steps to Install:
1. **Download the APK:** Open the following GitHub link on your Android phone:
   👉 [https://github.com/Melomania-be/mobile/releases](https://github.com/Melomania-be/mobile/releases)
   Download the latest package, e.g., **`melomania-v1.0.0.apk`**.
2. **Open the Package:** Once downloaded, tap the file in your notifications or download folder.
3. **Allow Installation from Unknown Sources (First time only):**
   * Android will block the installation initially for security reasons since it did not come from the Play Store.
   * Tap **Settings** on the prompt.
   * Toggle the option **Allow from this source** (or *Install unknown apps*) to enable it.
   * Tap the **Back** arrow.
4. **Install:** Tap **Install** on the prompt.
5. **Open:** Tap **Open** to launch the Melomania app!

---

## 📱 iOS / iPhone Installation (Home Screen Shortcut)

Direct sideloading of app packages is blocked by Apple on iPhones. Since the mobile app is a native shell wrapper that loads our live platform (`https://tool.melomania.be`), iOS users can add it to their home screen as a **Progressive Web App (PWA)** for the same native-app experience:

### Steps to Install:
1. **Open Safari:** On your iPhone, open the **Safari** browser and go to:
   👉 **[https://tool.melomania.be](https://tool.melomania.be)**
2. **Open Share Menu:** Tap the **Share** button (the square icon with an upward-pointing arrow at the bottom of the screen).
3. **Add to Home Screen:** Scroll down the option list and tap **Add to Home Screen**.
4. **Confirm:** Verify the name (Melomania) and tap **Add** in the top right corner.

A Melomania app icon will be created on your home screen. Tapping it opens the tool in fullscreen mode without the browser URL bar, behaving exactly like a native app.
